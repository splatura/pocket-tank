# Freenove FNK0104S Board Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the tank on the Freenove FNK0104S (4.0-inch ST7796S SPI LCD) as a fourth board with the same standing as the 1.8, the pendant and the watch. It ships publicly only after bench acceptance.

**Architecture:** A compile-time world `TANK_LCD40` (480 x 320) in `common/`, with per-board layout blocks where the 320 px glass cuts pages. New firmware ports for the ST7796 panel and an ADC battery estimate. Capability calls replace the `s_pmic` flag in `main.c`. The watch's saved SCREEN setting is reused through a new `TANK_SCREEN_MANUAL`. A known/published board list drives both CI workflows.

**Tech Stack:** C11 (`common/`, simulator on LVGL 9.2.2 + SDL2), ESP-IDF v5.4.1 (CI) / v5.5.5 (this machine), Python 3 tools, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-08-fnk0104s-board-design.md` (revision 2). Read it before any task; finding tags `(R#n)` refer to its appendix.

## Global Constraints

- Board id `fnk0104s`, display name `Freenove FNK0104S`, world macro `TANK_LCD40`, Kconfig `CONFIG_POCKET_TANK_LCD40`, sdkconfig fragment `firmware/sdkconfig.lcd40`, sim build `make FNK=1` → `fishsim-lcd40` in `build-lcd40/`.
- Tank 480 x 320; `ALGAE_CELL 16` (30 x 20 = 600 cells ≤ the save's 644); `VEG_SEG_PX 2.75f`; `PAGE_X 16`, `PAGE_Y -24` (derived, never written by hand).
- SAVE LAYOUT LOCK (`common/progression.c`): never move or edit a save field or its assert. This plan adds no save field.
- A board `#ifdef` goes only in `tank.h` geometry, layout-constant blocks in `render.h` / `render.c` / `setup.h` / `update.c` / `update.h`, and the firmware ports (docs/BOARDS.md). Feature logic never tests a board.
- Tests never use a literal pixel. They use layout constants with `PAGE_X` / `PAGE_Y`, or accessors (BOARDS.md rule 3).
- `make -C sim check-all` passes in every world after every task that touches `common/` or `sim/`.
- The 1.8, pendant and watch behave exactly as before. Their snapshot sets stay byte-identical except where a task says otherwise.
- `firmware/keys/` and `tools/boards.local.sh` are never committed.
- SPI default `CONFIG_POCKET_TANK_LCD40_SPI_MHZ=40`. Stripes are 20 rows (480 x 20 x 2 = 19,200 B each, two of them).
- Battery divider `F_BAT_DIVIDER 2.0f` (R14 = R15 = 100 k) until the bench measures it.
- Commit messages follow the repo's style (a plain-English summary), ending with the session's attribution lines.

## Review Focus

1. **Update mode at boot before the meter has samples:** `update_mode_run` runs about 1 s into boot. The ADC meter must already answer, or a low battery slips past the PLUG IN guard. Pinned in Task 10 (`battery_port_init` seeds the ring synchronously; the bench step reads `battery` in the director within 2 s of boot).
2. **A turned screen's taps:** with SCREEN TURNED on the LCD40, a tap must land where the picture shows it. Pinned in Task 5 (sim test of the sim's turned mapping) and Task 11 (`touch_port_set_inverted` path, bench step).
3. **The fullest milestones page:** 6 rows (6 fish, or 5 + NEW FRY) at 320 px. The last row must end above the TANK row's divider. Pinned in Task 3's bounds test (row 5's bottom ≤ `MSP_TANK_Y - 6`).
4. **BOOT still held when sleep arms its wake:** a keeper who holds BOOT must not wake the tank at once. Pinned in Task 13 (`enter_poweroff` waits for release, as `enter_sleep_for` does).
5. **No battery fitted, USB only:** the board must show PLUGGED and never raise the low-battery notice. Pinned in Task 10 (state logic: host seen → `BAT_PLUGGED`; `battery_lipo_frac` clamps) and bench step 5.

/* --selftest-bounds (2026-10-08, the FNK0104S's 320 px glass - spec R#4): every
 * tap target and title the layouts name lies wholly on the FRAME. Page
 * rectangles are page coordinates and are moved by PAGE_X / PAGE_Y; the card
 * and the toolbox are the frame's. The bowl's circle and the watch's corners
 * are their own layout blocks' business: this checks the frame's rectangle,
 * which every board must at least keep. */
typedef struct { const char *name; int x, y, w, h; bool page; } bounds_rect_t;
static int selftest_bounds(void) {
    const bounds_rect_t R[] = {
        /* the fish card and its toolbox (frame) */
        { "fish card",               RENDER_CARD_X, RENDER_CARD_Y, RENDER_CARD_W, RENDER_CARD_H, false },
        { "toolbox",                 RENDER_TOOLS_X, RENDER_TOOLS_Y, RENDER_TOOLS_W, RENDER_TOOLS_H, false },
        /* milestones (page) */
        { "milestones first row",    0, MSP_ROW_Y0, PAGE_W, MSP_ROW_H, true },
        { "milestones last row",     0, MSP_ROW_Y0 + (N_FISH_MAX - 1) * MSP_ROW_H, PAGE_W, MSP_ROW_H, true },
        { "milestones TANK row",     0, MSP_TANK_Y - 4, PAGE_W, 44, true },
        { "milestones SETTINGS",     MSP_SET_X, MSP_SET_Y, MSP_SET_W, MSP_CLOSE_H, true },
        { "milestones UPGRADES",     MSP_UPG_X, MSP_CLOSE_Y, MSP_UPG_W, MSP_CLOSE_H, true },
        { "milestones CLOSE",        MSP_CLOSE_X, MSP_CLOSE_Y, MSP_CLOSE_W, MSP_CLOSE_H, true },
        /* settings (page) */
        { "settings title",          0, SET_TITLE_Y, PAGE_W, 21, true },
        { "settings row 1",          SET_SEG_X, SET_SEG_Y(SET_ROW1_Y), 3 * SET_SEG_DX, SET_SEG_H, true },
        { "settings row 5",          SET_SEG_X, SET_SEG_Y(SET_ROW5_Y), 2 * SET_SEG_DX, SET_SEG_H, true },
        { "settings UPDATES",        SET_UPD_X, SET_FOOT_Y, SET_UPD_W, MSP_CLOSE_H, true },
        { "settings CLOSE",          SET_CLOSE_X, SET_FOOT_Y, MSP_CLOSE_W, MSP_CLOSE_H, true },
        /* the shop (page) */
        { "shop header",             SHP_COIN_X, SHP_COIN_Y, 64, 64, true },
        { "shop arrows",             SHP_ARROW_X0, SHP_ARROW_Y, SHP_ARROW_X1 + SHP_ARROW_W - SHP_ARROW_X0, SHP_ARROW_H, true },
        { "shop last row button",    SHP_BTN_X, SHP_ROW_Y0 + (SHP_PER_PAGE - 1) * SHP_ROW_DY, SHP_BTN_W, SHP_BTN_H, true },
        { "shop CLOSE",              SHP_CLOSE_X, MSP_CLOSE_Y, MSP_CLOSE_W, MSP_CLOSE_H, true },
        /* the setup flow and the update pages (page) */
        { "setup panel",             SETUP_X, SETUP_Y, SETUP_W, SETUP_H, true },
        { "setup title",             SETUP_X, SETUP_TITLE_Y, SETUP_W, 14, true },
        { "setup top buttons",       SETUP_X, SETUP_TOP_BTN_Y, SETUP_W, SETUP_BTN_H, true },
        { "setup foot buttons",      SETUP_X, SETUP_BTN_Y, SETUP_W, SETUP_BTN_H, true },
        { "update title",            0, UPD_TITLE_Y, PAGE_W, 21, true },
        { "update subtitle",         0, UPD_SUB_Y, PAGE_W, 14, true },
        { "update panel",            UPD_PANEL_X, UPD_PANEL_Y, UPD_PANEL_W, UPD_PANEL_H, true },
        { "update CHECK",            UPD_CHECK_X, UPD_CHECK_Y, UPD_CHECK_W, UPD_CHECK_H, true },
        { "update foot buttons",     UPD_BTN_L_X, UPD_BTN_Y, UPD_BTN_R_X + UPD_BTN_W - UPD_BTN_L_X, UPD_BTN_H, true },
        { "update CLOSE",            UPD_CLOSE_X, UPD_CLOSE_Y, UPD_CLOSE_W, UPD_CLOSE_H, true },
    };
    int fails = 0;
    for (size_t i = 0; i < sizeof R / sizeof R[0]; i++) {
        int x = R[i].x + (R[i].page ? PAGE_X : 0), y = R[i].y + (R[i].page ? PAGE_Y : 0);
        bool ok = x >= 0 && y >= 0 && x + R[i].w <= TANK_W && y + R[i].h <= TANK_H;
        printf("selftest-bounds: %-24s frame %4d,%4d %3dx%3d %s\n", R[i].name, x, y, R[i].w, R[i].h, ok ? "ok" : "OFF THE GLASS");
        if (!ok) fails++;
    }
    /* the fullest milestones page: the last row ends above the TANK row's divider (Review Focus 3) */
    if (MSP_ROW_Y0 + N_FISH_MAX * MSP_ROW_H > MSP_TANK_Y - 4) { printf("FAIL: the sixth milestones row runs into the TANK row (%d > %d)\n", MSP_ROW_Y0 + N_FISH_MAX * MSP_ROW_H, MSP_TANK_Y - 4); fails++; }
    /* the toolbox's tap test stops where its box does when it is not the bottom of the glass */
    if (render_tools_hit(RENDER_TOOLS_X + 20, RENDER_TOOLS_Y + RENDER_TOOLS_H / 2) != TOOL_SPONGE) { printf("FAIL: the toolbox's sponge does not answer at its centre\n"); fails++; }

    if (fails) { printf("FAIL: %d layout rectangles are off the glass (or overlap)\n", fails); return 1; }
    printf("selftest-bounds: OK\n");
    return 0;
}

 * (docs/board-fnk0104s.md; the spec's R#7, R#8, R#9, R#15).
 *
 * Stripe ownership is per buffer: every queued transfer gets a sequence
 * number, the done callback counts completions (SPI transfers finish in the
 * order they were queued), and a writer waits until the LAST transfer that
 * used ITS buffer is done. The buffer index carries across frames, so the
 * stripe count never matters. Brightness is LEDC PWM on the backlight; the
 * panel has no reset pin of its own (it shares CHIP_PU). */

static bool on_done(esp_lcd_panel_io_handle_t io, esp_lcd_panel_io_event_data_t *ev, void *ctx) {
    (void)io; (void)ev; (void)ctx;
    s_done++;
    BaseType_t hp = pdFALSE;
    xSemaphoreGiveFromISR(s_done_sig, &hp);
    return hp == pdTRUE;
}
static void wait_done(uint32_t seq) {                     /* until transfer #seq (1-based) is off the wire */
    int64_t t = esp_timer_get_time();
    while ((int32_t)(s_done - seq) < 0) xSemaphoreTake(s_done_sig, pdMS_TO_TICKS(100));
    s_prof_wait += esp_timer_get_time() - t;
}

static void send_frame(const uint16_t *fb) {
    if (s_inverted != s_inv_sent) {                       /* the flip: between frames, the wire empty */
        drain();
        uint8_t m = s_inverted ? MAD_TURNED : MAD_UPRIGHT; cmd(0x36, &m, 1);
        s_inv_sent = s_inverted;
    }
    static const uint8_t caset[4] = { 0, 0, (TANK_W - 1) >> 8, (TANK_W - 1) & 0xFF };
    static const uint8_t raset[4] = { 0, 0, (TANK_H - 1) >> 8, (TANK_H - 1) & 0xFF };
    cmd(0x2A, caset, 4); cmd(0x2B, raset, 4);             /* (tx_param waits for queued colour transfers itself) */
    for (int y = 0; y < TANK_H; y += STRIPE_ROWS) {
        int b = s_next; s_next ^= 1;
        wait_done(s_seq_of[b]);                           /* this buffer's last transfer is off the wire */
        const uint16_t *src = fb + (size_t)y * TANK_W;
        uint16_t *dst = s_stripe[b];
        for (int i = 0; i < STRIPE_PX; i++) dst[i] = (uint16_t)((src[i] << 8) | (src[i] >> 8));   /* the panel wants big-endian */
        int64_t t = esp_timer_get_time();
        esp_lcd_panel_io_tx_color(s_io, y == 0 ? 0x2C : 0x3C, dst, STRIPE_BYTES);   /* RAMWR, then RAMWR continue */
        s_prof_send += esp_timer_get_time() - t;
        s_seq_of[b] = ++s_queued;
    }
}
void display_port_flush(const uint16_t *fb) {
    send_frame(fb);
    if (s_light_owed) { drain(); backlight(s_brightness); s_light_owed = false; }   /* a whole picture first: no garbage flash */
}

bool display_port_init(void) {
    static const gpio_num_t held[] = { F_PIN_LCD_CS, F_PIN_LCD_BL, F_PIN_TP_RST, F_PIN_LCD_SCLK, F_PIN_LCD_MOSI, F_PIN_LCD_DC };
    for (size_t i = 0; i < sizeof held / sizeof held[0]; i++) gpio_hold_dis(held[i]);   /* a deep sleep's holds end here */
    i2c_master_bus_config_t bus = { .i2c_port = I2C_NUM_0, .sda_io_num = F_PIN_I2C_SDA, .scl_io_num = F_PIN_I2C_SCL,
        .clk_source = I2C_CLK_SRC_DEFAULT, .glitch_ignore_cnt = 7, .flags.enable_internal_pullup = true };
    if (i2c_new_master_bus(&bus, &s_i2c) != ESP_OK) { ESP_LOGE(TAG, "no I2C bus"); return false; }
    ledc_timer_config_t tc = { .speed_mode = LEDC_LOW_SPEED_MODE, .duty_resolution = LEDC_TIMER_8_BIT, .timer_num = BL_TIMER,
                               .freq_hz = 20000, .clk_cfg = LEDC_AUTO_CLK };
    ledc_channel_config_t cc = { .gpio_num = F_PIN_LCD_BL, .speed_mode = LEDC_LOW_SPEED_MODE, .channel = BL_CHANNEL,
                                 .timer_sel = BL_TIMER, .duty = 0, .hpoint = 0 };
    if (ledc_timer_config(&tc) != ESP_OK || ledc_channel_config(&cc) != ESP_OK) { ESP_LOGE(TAG, "no backlight PWM"); return false; }
    spi_bus_config_t sb = { .sclk_io_num = F_PIN_LCD_SCLK, .mosi_io_num = F_PIN_LCD_MOSI, .miso_io_num = -1,
                            .quadwp_io_num = -1, .quadhd_io_num = -1, .max_transfer_sz = STRIPE_BYTES };
    if (spi_bus_initialize(LCD_HOST, &sb, SPI_DMA_CH_AUTO) != ESP_OK) { ESP_LOGE(TAG, "no SPI bus"); return false; }
    s_done_sig = xSemaphoreCreateBinary();
    esp_lcd_panel_io_spi_config_t io = { .cs_gpio_num = F_PIN_LCD_CS, .dc_gpio_num = F_PIN_LCD_DC, .spi_mode = 0,
        .pclk_hz = CONFIG_POCKET_TANK_LCD40_SPI_MHZ * 1000 * 1000, .trans_queue_depth = 2, .on_color_trans_done = on_done,
        .lcd_cmd_bits = 8, .lcd_param_bits = 8 };
    if (esp_lcd_new_panel_io_spi((esp_lcd_spi_bus_handle_t)LCD_HOST, &io, &s_io) != ESP_OK) { ESP_LOGE(TAG, "no panel IO"); return false; }
    size_t dma0 = heap_caps_get_free_size(MALLOC_CAP_DMA | MALLOC_CAP_INTERNAL), big0 = heap_caps_get_largest_free_block(MALLOC_CAP_DMA | MALLOC_CAP_INTERNAL);
    for (int i = 0; i < 2; i++) {
        s_stripe[i] = heap_caps_malloc(STRIPE_BYTES, MALLOC_CAP_DMA | MALLOC_CAP_INTERNAL);
        if (!s_stripe[i]) { ESP_LOGE(TAG, "no DMA stripe %d (%u B; DMA free %u, largest %u)", i, STRIPE_BYTES, (unsigned)dma0, (unsigned)big0); return false; }
    }
    ESP_LOGI(TAG, "stripes 2 x %u B | internal DMA free %u -> %u, largest block %u -> %u (spec R#8)", STRIPE_BYTES,
             (unsigned)dma0, (unsigned)heap_caps_get_free_size(MALLOC_CAP_DMA | MALLOC_CAP_INTERNAL),
             (unsigned)big0, (unsigned)heap_caps_get_largest_free_block(MALLOC_CAP_DMA | MALLOC_CAP_INTERNAL));
    for (size_t i = 0; i < sizeof INIT / sizeof INIT[0]; i++) {
        cmd(INIT[i].c, INIT[i].n ? INIT[i].p : NULL, INIT[i].n);
        if (INIT[i].ms) vTaskDelay(pdMS_TO_TICKS(INIT[i].ms));
        if (INIT[i].c == 0x11) s_slpout_us = esp_timer_get_time();
    }
    memset(s_stripe[0], 0, STRIPE_BYTES); memset(s_stripe[1], 0, STRIPE_BYTES);
    static uint16_t *black; if (!black) black = heap_caps_calloc(TANK_W * TANK_H, 2, MALLOC_CAP_SPIRAM);
    if (black) send_frame(black);                         /* the glass black before the light */
    s_light_owed = true;
    ESP_LOGI(TAG, "board: the FNK0104S (ST7796S 480x320 over SPI at %d MHz)", CONFIG_POCKET_TANK_LCD40_SPI_MHZ);
    return true;
}

void display_port_sleep(void) {                           /* backlight off, DISPOFF, SLPIN (+5 ms), the wire empty first */
    drain();
    backlight(0);
    int64_t since = esp_timer_get_time() - s_slpout_us;
    if (since < 120000) vTaskDelay(pdMS_TO_TICKS((120000 - since) / 1000 + 1));
    cmd(0x28, NULL, 0); cmd(0x10, NULL, 0);
    vTaskDelay(pdMS_TO_TICKS(5));
}
void display_port_wake(void) {                            /* SLPOUT (+120 ms), DISPON; the light after one whole frame */
    cmd(0x11, NULL, 0); s_slpout_us = esp_timer_get_time();
    vTaskDelay(pdMS_TO_TICKS(120));
    cmd(0x29, NULL, 0);
    s_light_owed = true;
}
void display_port_deep_standby(void) { }                 /* SLPIN is the ST7796S's lowest state: display_port_sleep sent it */
void display_port_deep_sleep_bus(void) {                  /* a powered panel's inputs never float: clock, data and D/C low */
    static const gpio_num_t lo[] = { F_PIN_LCD_SCLK, F_PIN_LCD_MOSI, F_PIN_LCD_DC };
    for (size_t i = 0; i < sizeof lo / sizeof lo[0]; i++) { gpio_reset_pin(lo[i]); gpio_set_direction(lo[i], GPIO_MODE_OUTPUT); gpio_set_level(lo[i], 0); gpio_hold_en(lo[i]); }
}
void display_port_deep_sleep_pins(bool tp_awake_high) {   /* CS high (deselected), backlight low, the touch chip in reset */
    gpio_reset_pin(F_PIN_LCD_CS); gpio_set_direction(F_PIN_LCD_CS, GPIO_MODE_OUTPUT); gpio_set_level(F_PIN_LCD_CS, 1); gpio_hold_en(F_PIN_LCD_CS);

    gpio_set_level(F_PIN_TP_RST, tp_awake_high ? 1 : 0); gpio_hold_en(F_PIN_TP_RST);
}

    { 3770, 0.30f }, { 3790, 0.35f }, { 3800, 0.40f }, { 3820, 0.45f }, { 3840, 0.50f }, { 3850, 0.55f },
    { 3870, 0.60f }, { 3910, 0.65f }, { 3950, 0.70f }, { 3980, 0.75f }, { 4020, 0.80f }, { 4080, 0.85f },
    { 4110, 0.90f }, { 4150, 0.95f }, { 4200, 1.00f },
};
float battery_lipo_frac(int mv) {
    const int n = (int)(sizeof LIPO / sizeof LIPO[0]);
    if (mv <= LIPO[0].mv) return 0.0f;
    if (mv >= LIPO[n - 1].mv) return 1.0f;
    for (int i = 1; i < n; i++)
        if (mv <= LIPO[i].mv) return LIPO[i - 1].f + (LIPO[i].f - LIPO[i - 1].f) * (float)(mv - LIPO[i - 1].mv) / (float)(LIPO[i].mv - LIPO[i - 1].mv);
    return 1.0f;
}
int battery_median_mv(const int *mv, int n) {
    int s[16]; if (n > 16) n = 16;
    for (int i = 0; i < n; i++) s[i] = mv[i];
    for (int i = 1; i < n; i++) for (int j = i; j > 0 && s[j - 1] > s[j]; j--) { int t = s[j]; s[j] = s[j - 1]; s[j - 1] = t; }
    return n % 2 ? s[n / 2] : (s[n / 2 - 1] + s[n / 2]) / 2;
}
int battery_hyst_pct(int shown_pct, float frac) {
    int p = (int)(frac * 100.0f + 0.5f);
    if (shown_pct < 0 || p >= shown_pct + 2 || p <= shown_pct - 2) return p;
    return shown_pct;
}

## Phase D: bench acceptance (when the board arrives)

### Task 17: On the glass, then publish

This task runs with the board on the bench. Each step records its result in `docs/board-fnk0104s.md`'s bench table and commits it. If a step fails, stop: it becomes its own fix task, with superpowers:systematic-debugging.

- [ ] **Step 1: Back up the factory image, first flash**

`esptool.py --chip esp32s3 -p <port> -b 921600 read_flash 0 0x1000000 ~/fnk0104s-factory.bin`, then `tools/flash_lcd40.sh --full`. Pass: the boot log shows `board: the FNK0104S`, the stripe/DMA line, and `battery from GPIO9`. The glass shows the tank: colours right (water teal, not orange: if swapped, flip `MAD_BGR`), not inverted (if negative, drop `0x21`), and the right way up.

- [ ] **Step 2: Boot matrix**

Cold boot (unplug, plug), RESET, BOOT+RESET (download mode answers `esptool.py chip_id`), and `restart` from the director: each comes up clean.

- [ ] **Step 3: Speed**

Record fps at 40 MHz from the boot log's frame profile. Then build with `CONFIG_POCKET_TANK_LCD40_SPI_MHZ=80` and run the soak: one hour with Wi-Fi up, sound on and the advisor running, twenty sleep/wake cycles, and a cold start. 80 MHz becomes the default (in `sdkconfig.lcd40`) only if no frame was corrupt.

- [ ] **Step 4: Touch**

Tap the four corners and the centre, in SCREEN NORMAL and TURNED. If taps land rotated 180 degrees from the picture, set `F_TOUCH_TURN 1` in `board_pins.h`. Then run `ota calib` and put the fit's constants into a `TANK_LCD40` branch of `cal_point`, as the watch has.

- [ ] **Step 5: Sound and battery**

Cues play, and there is no pop at the amp's switch. Measure the cell with a meter at 3 points from full to about 3.5 V against `battery` in the director, and set `F_BAT_DIVIDER` to the fit. Check: USB from a computer shows PLUGGED; a wall charger shows battery; no cell fitted on USB shows PLUGGED with no low-battery notice. Read `battery` in the director within 2 s of a boot (Review Focus 1).

- [ ] **Step 6: Sleep current**

Measure with a meter in series at the cell, unplugged, backlight off, no SD card, RGB LED off: awake, the light-sleep grace, deep sleep, and the ESP32 held in reset (the parts' floor). Do 20 sleep/wake cycles with a held-key wake. Pass: deep sleep within 0.5 mA of the held-in-reset floor. Record the implied battery life in the doc and in the installer note.

- [ ] **Step 7: Updates**

On a factory board, the installer end to end with `make_installer.py --include-unpublished` served locally. Then one signed Wi-Fi update from a pre-release (a `-rc` tag, which "latest" skips). Check that a wrong-board image is refused (the 1.8's image offered to it) and that a pulled cable mid-update rolls back.

- [ ] **Step 8: Publish**

When steps 1-7 pass, set the FNK0104S's published flag to `True` in `tools/pt_boards.py`, update `tools/test_pt_boards.py` to match (four published), drop "(coming: bench testing)" from the README, and commit: "The FNK0104S ships: bench acceptance passed (docs/board-fnk0104s.md)".
